# Acceptance checklist для Codex

[ ] Поиск выполнен по всему Казахстану и нескольким независимым классам источников.
[ ] Компании реальны, источники и дата проверки указаны.
[ ] Рекламный сигнал подтвержден публично (не по догадке).
[ ] Разделены FACT / INFERENCE / UNKNOWN.
[ ] Этический фильтр применен до коммерческой оценки.
[ ] Проверка дубликатов с Битрикс24 READ ONLY; ошибки проверки не скрыты.
[ ] Старые клиенты и HOLD не входят в топ новых лидов.
[ ] На компанию один приоритетный продукт и одна обоснованная гипотеза.
[ ] Подготовлены адресные письмо, тема, звонковый opening, следующий шаг.
[ ] Для визуальных email есть узнаваемый публичный контекст, явная демонстрационная маркировка и корректный бренд отправителя.
[ ] Работает первый кадр без анимации и текстовый вариант без изображений.
[ ] Нет отправок/создания сущностей CRM без согласования.
[ ] Есть Excel и готовые к просмотру HTML/визуальные образцы (не только код).
[ ] Честно указано фактическое число готовых компаний, отсутствие данных, ограничения.
[ ] Есть воронка обратной связи по итогам контактов и схема сравнения обычного и визуального письма.
